Linux (amd64, arm64) and macOS (Apple Silicon)

Install script

Detects your OS and architecture, downloads the matching tarball, verifies its checksum and extracts it to /usr/local, or to the prefix you give. It needs a Unix shell: on Windows, use the Windows build.

curl -fsSL https://benoitc.github.io/erlang-dist/install.sh | sh

A specific version, or a custom prefix:

curl -fsSL https://benoitc.github.io/erlang-dist/install.sh | sh -s -- X.Y.Z
curl -fsSL https://benoitc.github.io/erlang-dist/install.sh | sh -s -- X.Y.Z $HOME/.local/erlang

Ubuntu 22.04, 24.04, 26.04 and Debian 12, 13, on amd64 and arm64

APT repository

Pick your distro: ubuntu2204, ubuntu2404, ubuntu2604, debian11, debian12 or debian13. This example is for Ubuntu 24.04:

echo "deb [trusted=yes] https://github.com/benoitc/erlang-dist/releases/download/ apt-ubuntu2404/" | \
    sudo tee /etc/apt/sources.list.d/erlang-dist.list
sudo apt update && sudo apt install erlang-29

Pin a version with sudo apt install erlang-29=29.1.

Unsigned: [trusted=yes] turns off APT's signature check for this source. See what is verified.

Rocky Linux 9, 10 and CentOS Stream 9, 10, on amd64 and arm64

YUM/DNF repository

Pick your distro: rocky9, rocky10, cs9 or cs10. The generic erlang-dist.repo serves the CentOS Stream builds to any EL9 or EL10 system.

sudo curl -fsSL https://benoitc.github.io/erlang-dist/rpm/erlang-dist-cs9.repo \
    -o /etc/yum.repos.d/erlang-dist.repo
sudo dnf install erlang-29

Pin a version with sudo dnf install erlang-29-29.1.

Unsigned: the repository files set gpgcheck=0. See what is verified.

Windows 10, 11 and Server, x64

Windows installer or zip

Each release includes the official Erlang/OTP x64 build from the erlang/otp project: an installer (.exe) and a zip, checked against the erlang/otp release digests. Run the installer, or unpack the zip anywhere. In PowerShell:

$v = "X.Y.Z"
Invoke-WebRequest "https://github.com/benoitc/erlang-dist/releases/download/OTP-$v/erlang-$v-windows-amd64.zip" -OutFile erlang.zip
Expand-Archive erlang.zip -DestinationPath "$env:LOCALAPPDATA\erlang"
& "$env:LOCALAPPDATA\erlang\bin\erl.exe"

Add %LOCALAPPDATA%\erlang\bin to your PATH to use erl from any shell.

Any supported platform

Manual download

Download a tarball, package or Windows file from GitHub Releases, then check it against the release's SHA256SUMS. On Linux:

v=X.Y.Z
curl -fsSLO https://github.com/benoitc/erlang-dist/releases/download/OTP-$v/erlang-$v-linux-amd64.tar.gz
curl -fsSL https://github.com/benoitc/erlang-dist/releases/download/OTP-$v/SHA256SUMS | grep linux-amd64.tar.gz | sha256sum -c
sudo tar xzf erlang-$v-linux-amd64.tar.gz -C /

On macOS, check with shasum -a 256 -c instead of sha256sum -c. On Windows, compare the output of Get-FileHash .\erlang.zip with the line for that file in SHA256SUMS.

What is verified

Checksums

Every release publishes SHA256SUMS for its files. The install script checks it. A checksum detects a corrupted download; it comes from the same release, so it is not a signature.

No package signing yet

Packages are not signed. The APT source uses [trusted=yes] and the DNF repository files set gpgcheck=0.

Who built what

Linux and macOS packages are built by this project from the upstream erlang/otp releases. The Windows files are the official erlang/otp builds, checked against the upstream digests.

Repository changes (2026-10-04)

Packages are now downloaded from GitHub Releases; this site only serves the repository indexes.

  • APT users: action required. The https://benoitc.github.io/erlang-dist/apt stable main repository is retired and apt update now fails with changed its 'Label' value ... MOVED. Replace your source line with the one for your distro (ubuntu2204, ubuntu2404, ubuntu2604, debian11, debian12, debian13): 
    echo "deb [trusted=yes] https://github.com/benoitc/erlang-dist/releases/download/ apt-ubuntu2404/" | \
    sudo tee /etc/apt/sources.list.d/erlang-dist.list
sudo apt update
  • RPM users: nothing to do. The erlang-dist-rocky9.repo, erlang-dist-rocky10.repo, erlang-dist-cs9.repo and erlang-dist-cs10.repo files keep working. The generic erlang-dist.repo now serves the CentOS Stream 9/10 builds for any EL9/EL10 system; download it again if you use it.
  • All versions stay installable. Older releases are no longer dropped; pin one with apt install erlang-29=29.1 or dnf install erlang-29-29.1.
  • Debian 11 is end of life and no longer built. Its packages, up to 29.0.6, stay available.
  • Rocky Linux 9 builds are back, starting with 29.1.1, 28.5.0.7 and 27.3.4.11.
  • New platforms: Ubuntu 26.04, Debian 13, Rocky Linux 10, and arm64 for Debian and Ubuntu 22.04.
  • Windows: releases now include the official Erlang/OTP x64 installer and zip.
  • macOS: the build now includes OpenSSL 3.5, so crypto and ssl work without Homebrew's openssl@3.
  • Installer fixed: install.sh downloaded from a wrong URL and installed into the wrong directory. It now works, including with a custom prefix: 
    curl -fsSL https://benoitc.github.io/erlang-dist/install.sh | sh -s -- X.Y.Z $HOME/.local/erlang
