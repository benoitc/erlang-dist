Repository changes (2026-10-04)

Packages are now downloaded from GitHub Releases; this site only serves the repository indexes.

  • APT users: action required. The https://benoitc.github.io/erlang-dist/apt stable main repository is retired and apt update now fails with changed its 'Label' value ... MOVED. Replace your source line with the one for your distro (ubuntu2204, ubuntu2404, ubuntu2604, debian11, debian12, debian13): 
    echo "deb [trusted=yes] https://github.com/benoitc/erlang-dist/releases/download/ apt-ubuntu2404/" | \
    sudo tee /etc/apt/sources.list.d/erlang-dist.list
sudo apt update
  • RPM users: nothing to do. The erlang-dist-rocky9.repo, erlang-dist-rocky10.repo, erlang-dist-cs9.repo and erlang-dist-cs10.repo files keep working. The generic erlang-dist.repo now serves the CentOS Stream 9/10 builds for any EL9/EL10 system; download it again if you use it.
  • All versions stay installable. Older releases are no longer dropped; pin one with apt install erlang-29=29.1 or dnf install erlang-29-29.1.
  • Debian 11 is end of life and no longer built. Its packages, up to 29.0.6, stay available.
  • Rocky Linux 9 builds are back, starting with 29.1.1, 28.5.0.7 and 27.3.4.11.
  • New platforms: Ubuntu 26.04, Debian 13, Rocky Linux 10, and arm64 for Debian and Ubuntu 22.04.
  • Windows: releases now include the official Erlang/OTP x64 installer and zip.
  • macOS: the build now includes OpenSSL 3.5, so crypto and ssl work without Homebrew's openssl@3.
  • Installer fixed: install.sh downloaded from a wrong URL and installed into the wrong directory. It now works, including with a custom prefix: 
    curl -fsSL https://benoitc.github.io/erlang-dist/install.sh | sh -s -- 29.1.1 $HOME/.local/erlang

Quick Install

curl -fsSL https://benoitc.github.io/erlang-dist/install.sh | sh

Or specify a version:

curl -fsSL https://benoitc.github.io/erlang-dist/install.sh | sh -s -- 29.1.1

APT Repository (Debian/Ubuntu)

Pick your distro: ubuntu2204, ubuntu2404, ubuntu2604, debian11, debian12 or debian13.

echo "deb [trusted=yes] https://github.com/benoitc/erlang-dist/releases/download/ apt-ubuntu2404/" | \
    sudo tee /etc/apt/sources.list.d/erlang-dist.list
sudo apt update && sudo apt install erlang-29

YUM/DNF Repository (RHEL/Rocky/CentOS)

Pick your distro: rocky9, rocky10, cs9 or cs10.

sudo curl -fsSL https://benoitc.github.io/erlang-dist/rpm/erlang-dist-cs9.repo \
    -o /etc/yum.repos.d/erlang-dist.repo
sudo dnf install erlang-29

Windows

Each release includes the official Erlang/OTP x64 installer (.exe) and zip, checked against the erlang/otp release digests.

$v = "29.1.1"
Invoke-WebRequest "https://github.com/benoitc/erlang-dist/releases/download/OTP-$v/erlang-$v-windows-amd64.zip" -OutFile erlang.zip
Expand-Archive erlang.zip -DestinationPath "$env:LOCALAPPDATA\erlang"
& "$env:LOCALAPPDATA\erlang\bin\erl.exe"
